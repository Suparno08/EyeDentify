#eye-dentify
👁️ EyeDentify - Face Recognition Attendance System
EyeDentify is a smart web-based attendance management system that uses Face Recognition to automate student attendance. The system identifies registered students through live face scanning and records attendance automatically while preventing duplicate entries for the same class session.
🌐 Live Demo
Website:https://eye-dentify-sand.vercel.app/


📌 Project Overview
Traditional attendance systems are often time-consuming and prone to proxy attendance. EyeDentify addresses these challenges by using face recognition technology to identify students and mark attendance automatically.
A student's attendance can only be marked once during a class session, making the system more secure and reducing the possibility of proxy attendance.

✨ Features
👤 Student Enrollment
• Register student details
• Upload one or multiple face photographs
• Store student information for future recognition
📷 Live Face Recognition
• Real-time face scanning using the device camera
• Automatic student identification
• Attendance marking upon successful recognition
🛡️ Anti-Proxy Attendance
• Prevents duplicate attendance entries
• Attendance can only be marked once per student for a class session
📊 Attendance Portal
• Search attendance using Roll Number
• View attendance records instantly
📁 CSV Export
• Download attendance records as CSV files
• Easy integration with Microsoft Excel and Google Sheets

🚀 How to Use
Step 1: Register Students
1. Open the Enrollment section.
2. Enter: 
◦ Student Name
◦ Roll Number
◦ Department/Class
3. Upload student face photographs.
4. Click Register Student Face.
Step 2: Load Face Models
1. Go to the Scanner section.
2. Click Load Face Models.
Step 3: Start Recognition
1. Click Start Front Camera.
2. Show the registered student's face to the camera.
3. Attendance will be marked automatically upon a successful match.
Step 4: Check Attendance
1. Open the Student Portal.
2. Enter the student's Roll Number.
3. Click View Attendance.
Step 5: Export Records
1. Open the Records section.
2. Download attendance data as a CSV file.
